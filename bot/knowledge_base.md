Клиенты постоянно смешивают эти две услуги. Сначала выясни, о чём речь.

Цена - за одно рабочее место. Одна машина рассчитана строго на одно
одновременное подключение, разделить её между сотрудниками нельзя.

Услуги можно брать вместе или по отдельности.
При аренде от двух виртуальных рабочих мест Revit Server и общий сетевой диск
подключаем бесплатно на том же железе, пинг между ними меньше 3 мс.

## Локации: два разных вопроса, не путать

Клиенты спрашивают про заграницу в двух разных смыслах.
Сначала пойми, о чём речь, потом отвечай.

Первый вопрос - где физически стоит сервер. Это выбор локации, зависит от тарифа.
Список локаций смотри в тарифах выше. На LOD 100 и на всех тарифах VDI
зарубежных локаций нет, они начинаются с LOD 200.
Если клиенту нужна зарубежная локация, а он смотрит на младший тариф -
это повод предложить старший, а не отказ.

Список локаций - ориентир, а не обещание. Наличие свободных мощностей в конкретной
стране уточняем каждый раз, прежде чем что-то подтвердить. Гарантий не даём.

Второй вопрос - сможет ли человек подключиться, находясь за границей. Это про VPN.
Формулировать осторожно, без технических подробностей:
в России сервис работает штатно; из-за рубежа подключение возможно,
но зависит от страны и провайдера; в отдельных странах VPN блокируется полностью;
если сложности возникли, есть запасные варианты, подбираем индивидуально.

Наличие сервера в стране не означает, что из этой страны можно подключиться.
Это два разных вопроса.

Локация сервера фиксируется при запуске и при расширении не меняется.

## Подключение

Основная схема - RSLauncher, наш собственный клиент. Внутри он поднимает
туннель на базе оригинального WireGuard, отдельный VPN-клиент ставить не нужно.

При первом запуске пользователь вводит персональный токен, токен выдаём мы.
Раньше вместо токена была ссылка - старая схема выводится из обращения,
новые клиенты подключаются через лаунчер сразу.

Лаунчер сам подключает сетевой диск Z, отдельно настраивать не нужно.

Токен персональный: один пользователь - один токен. Два одновременных
подключения по одному токену работать не будут. Если человек сел за другой
компьютер, на первом надо отключиться.

Что дальше, в зависимости от услуги:
- Revit Server: делать больше ничего не нужно. Лаунчер сам прописывает RSN.ini
  и подключает сетевой диск. Работа идёт через вкладку Revit «Совместная работа»,
  сервер появляется в списке сам
- VDI: лаунчер сам открывает удалённый стол, Revit на нём уже подключён к серверу

Подключаться можно с любого устройства: компьютер, ноутбук, тонкий клиент
с поддержкой RDP. На macOS схема другая - клиент WireGuard плюс подключение
через Windows App, конфиг выдаём отдельно.

VPN входит в стоимость услуги и отдельно не оплачивается. Есть подробная
инструкция, при сложностях помогаем удалённо через AnyDesk.

Канал зарезервирован целиком, скорость по тарифу. Итоговая скорость упирается
в интернет самого пользователя.

Конфиденциальность: канал зашифрован, подключение только через VPN,
порты Revit Server закрыты из интернета, попасть на сервер извне нельзя.
Раздел о конфиденциальности прописан в договоре.

## Если не подключается

Разбирать по порядку, сверху вниз.

Не поднимается виртуальный сетевой адаптер.
В командной строке выполнить netsh winsock reset, затем netsh int ip reset,
после этого перезагрузить компьютер.

Конфликт с другими VPN-клиентами.
Частая причина - накопившиеся виртуальные сетевые адаптеры от разных VPN.
Удалить лишние вручную, оставив физический, затем переустановить
последнюю версию лаунчера.

У пользователя есть свой VPN и он нужен ему для работы.
Сначала пробуем оставить: наш туннель маршрутизирует только трафик до сервера
и обычно не конфликтует. Если конфликт есть - в настройках стороннего VPN
исключить маршрутизацию на наш сервер, чтобы трафик не шёл длинной петлёй
через другую страну. Если и это не помогло - свой VPN выключить полностью.
Именно выключить, а не приостановить: приостановленный клиент оставляет
за собой виртуальный адаптер и продолжает мешать.

У пользователя нет прав администратора или лаунчер не идёт совсем.
Запасной путь: настраиваем IKEv2 или L2TP/IPsec, они встроены в Windows
и прав администратора не требуют. Это не основная схема, предлагаем только
когда обычная не заработала. Если L2TP/IPsec не устанавливает соединение,
помогает правка реестра:
REG ADD HKLM\SYSTEM\CurrentControlSet\Services\PolicyAgent /v AssumeUDPEncapsulationContextOnSendRule /t REG_DWORD /d 2 /f

Лаунчер зависает на этапе подключения.
Перезагрузить роутер, попробовать мобильный интернет.
Если не помогло - подключаем технического специалиста через AnyDesk.

Внезапно отвалились все пользователи разом.
Скорее всего, причина на нашей стороне, например смена IP у провайдера.
Попросить перезапустить лаунчер, параллельно проверить самим.

Работает нестабильно, рвётся соединение.
Уточнить, подключён ли пользователь по Wi-Fi. Wi-Fi влияет сильно,
провод решает проблему в большинстве случаев.

При жалобах на нестабильность не обещать стопроцентную гарантию:
часть причин на стороне провайдера клиента и нами не контролируется.

## Модель долго открывается

Это почти никогда не VPN - туннель скорость не режет. Проверять по порядку:

1. Битые связи в диспетчере связей. Если файл перемещён, удалён или лежит
   на локальном диске, Revit ждёт таймаута по каждой связи при открытии
2. Лишние открытые рабочие наборы - отключить ненужные
3. Wi-Fi вместо провода
4. Параллельно включённый сторонний VPN - на время открытия отключить
5. Проверить пинг до сервера

Отдельная частая причина: связи разбросаны по разным местам - часть на сетевом
диске, часть на локальном C, часть на стороннем облаке. Каждое такое место -
потенциальная точка отказа. Когда сетевой диск отваливается, Windows не помечает
его мёртвым сразу, и каждое обращение висит на таймаутах SMB десятками секунд.
Правильное решение - собрать все связи в одном месте.

## Акселератор

Отдельно не продаём и в предложениях не упоминаем. Тема поднимается ситуативно:
когда клиент спрашивает сам или когда в офисе большая команда на одном канале.

Порядок настройки, если дошло до дела:
1. На подготовленную машину установить ту же версию Revit Server, что и на нашем
   сервере, выбрав при установке только роль Accelerator. Если Revit Server уже
   стоит с тремя ролями - удалить и переустановить с одной
2. В rsn.ini прописать IP нашего Revit Server
3. На эту же машину установить клиент WireGuard и подключить нашим конфигом
4. У пользователей в Revit указать IP локального акселератора

Акселератор не помогает при блокировках VPN, он решает другую задачу.

Локальный акселератор прямо на машине пользователя технически возможен
через docker, но массово мы это не применяем из-за сложности развёртывания.

## Пользователи, доступы, личный кабинет

У клиента есть личный кабинет, где администратор сам добавляет и удаляет
пользователей и видит статистику по времени работы каждого. Статистика доступна
всем, кто уже переведён в панель.

Перевод на личный кабинет бесплатный. После перевода всех пользователей
старые доступы отключаются.

Количество слотов определяется тарифом, обычно плюс один резервный.
Когда все слоты заняты - либо освободить неиспользуемые учётные записи,
либо перейти на более крупный тариф.

Расширение количества пользователей: подписываем дополнительное соглашение,
расширяем лимит в личном кабинете, дальше клиент добавляет людей сам.
Мощность сервера увеличиваем в ночное время с кратковременной перезагрузкой.
Перерасчёт можно сделать сразу или перенести на следующий месяц.

Если пользователей больше сотни, команду лучше делить на отдельные серверы.

У клиента есть доступ в админ-панель Revit Server, где он сам создаёт структуру
папок и управляет проектами. Доступ по RDP к самому Revit Server не предоставляется,
сервер находится на нашей поддержке.

На VDI у клиента прямой админ-доступ к преднастроенной машине, она всегда активна.
Панель управления параметрами самой виртуальной машины не предоставляется.

## Разграничение прав

Штатного разграничения прав по проектам на Revit Server нет - Autodesk
специально не внедряет эту функцию.

Обходной путь, который иногда предлагаем: создать несколько учётных записей
по группам, например по разделам проектирования, и дать каждой доступ только
в свою папку. Конструкторы видят только свою папку, архитекторы - свою.
Это не полноценное разграничение прав, но задачу обычно закрывает.

Если нужна полная изоляция - отдельный сервер под каждый проект.

Для VDI: технически можно ограничить буфер обмена, передачу файлов через RDP,
подключение локальных дисков и USB. Но это нестандартная настройка, отдельно
её не предлагаем - если клиент спрашивает, говорим, что вопрос решаемый,
и уточняем детали у коллег.

По умолчанию копирование файлов между виртуальным столом и локальным
компьютером разрешено.

## Файлы, сетевой диск, RSManager

Сетевой диск входит в услугу. Объём общий с проектами Revit Server.
При необходимости объём можно увеличить, стоимость считаем индивидуально.

RSManager - наша собственная утилита, созданная на базе официального API Autodesk
для пакетной выгрузки, которой нет в стандартном интерфейсе. Portable-версия,
установка не требуется, изменений в реестр не вносит.

Перенос проектов со старого сервера: все пользователи синхронизируются
и закрывают модели, затем копируют папку Projects, архивируют и присылают нам.
Мы размещаем архив на новом сервере. Инструкция по переносу предоставляется.

Очистка кэша Revit:
1. Закрыть Revit
2. Удалить файлы с «backup» из «Мои документы»
3. Все синхронизируются и закрывают файл
4. Открыть, «Отсоединить от central», сохранить как центральный

Восстановление из резервной копии делаем быстро, но конкретное время
не обещаем - зависит от объёма.

## Производительность

Мощность компьютера пользователя на работу Revit Server не влияет,
она влияет только на работу его собственного Revit.

Если модель тормозит при отрисовке и Revit вылетает, частая причина -
нехватка дискретного GPU. В моделях с большим количеством элементов обычная
отрисовка перегружает систему. Решение - переход на тариф с видеокартой.

Если жалуются на скорость из удалённого региона, дело обычно в пинге,
а не в ширине канала. Варианты: акселератор ближе к пользователям
или виртуальное рабочее место в городе, где стоит сервер.

## Revit: версии и софт

Версия Revit у всех участников должна совпадать - сервер и клиенты работают
на одной версии года. Revit Server поддерживает версии 2019-2027.
Revit 2027 доступен и на Revit Server, и на VDI.

Одновременно на одном сервере могут работать Revit Server разных версий,
например 2022 и 2024.

Revit на рабочие машины сотрудников клиент устанавливает сам - это обычная
программа Autodesk. Мы настраиваем VPN, подключение к серверу и сетевой диск,
это входит в стоимость аренды.

Если клиенту нужен вариант, где Revit тоже на нашей стороне - это VDI.

На VDI можно ставить любое ПО: Node.js, Python, pyRevit, кастомные плагины,
1С, браузеры. Права администратора полные, мы не ограничиваем.
Лицензии на стороннее ПО клиент приобретает сам.
AEC Collection целиком не разворачиваем, программы ставим по отдельности.

Дополнительно на VDI: SSH через OpenSSH Server, локальные порты разрешены,
исходящий трафик из РФ со всеми вытекающими - при необходимости клиент
может использовать свой VPN.

Если после подключения лаунчера сервер не появился в списке в Revit -
обычно помогает переустановка Revit, это известный глюк.

## Договор и оплата

Схема: рамочный договор на год с автоматической пролонгацией плюс приложение,
в котором указаны услуги, сроки и объёмы. Сам договор описания услуг не содержит.

Продление идёт через оплату: оплатили - продлеваем на следующий месяц,
не оплатили - доступ не продлеваем. Отдельной услуги заморозки нет.
Если два месяца подряд оплаты нет, приложение считается расторгнутым,
при возвращении заключаем новое приложение к тому же рамочному договору.

При отсутствии оплаты данные хранятся 10 дней. Без предупреждения ничего
не удаляем, при расторжении всегда даём время на выгрузку.

Гарантия доступности: суммарный простой по нашей вине не более 6 часов в месяц.
Раздел о конфиденциальности в договоре есть, при необходимости согласуем
формулировку клиента. Клиентский NDA подписываем.

Оплата авансовая, помесячная. Юрлица - расчётный счёт, документы через ЭДО
(Диадок или СБИС). Физлица - по персональной ссылке через СБП.
Можно внести предоплату сразу за несколько месяцев.

Первый счёт обычно неполный, за остаток текущего месяца, дальше выходим
на ровные календарные месяцы.

Дата начала оказания услуг - момент фактической передачи доступов.

Для договора с юрлицом нужна карточка организации: наименование, ИНН, КПП,
ОГРН, ОКПО, юридический и почтовый адрес, банковские реквизиты, генеральный
директор, контактное лицо по договору с телефоном и почтой.
Дополнительно нужен контакт ответственного за техническое взаимодействие -
именно с этого контакта принимаются запросы на восстановление бэкапа,
блокировку пользователей и подобные действия.

Смена тарифа оформляется дополнительным соглашением. Переход между тарифами
обычно быстрый, дольше только переход с конфигурации без GPU на конфигурацию
с GPU - там физически другие серверы и требуется перенос.
